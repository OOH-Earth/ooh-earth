# Famous Ad Locations curated registry

The V1 registry is editorial evidence, not a global fame ranking. A record may
be added only when a reviewer can inspect a stable source that documents the
advertising significance of the named place.

Each record must provide:

- a stable identifier and reference coordinates;
- an explicit relationship (`AT`, `WITHIN`, `NEAR`, `DOCUMENTED_AT`,
  `ASSOCIATED_WITH`, or `UNKNOWN`);
- a bounded matching radius justified by that relationship;
- a source URL and source identifier where available;
- a concise factual summary written by OOH Earth, without copying protected
  source prose;
- historical period only when the source supports it;
- review date, evidence status, licence classification and attribution.

V1 does not copy or proxy third-party images. Media requires a separate,
file-level licence review. Proximity alone must never be promoted to `AT`, and
no record should be added from popularity, search ranking or unsourced claims.

The current reviewed example is Piccadilly Lights, based on the official
operator source: <https://www.piccadillylights.co.uk/en/>. The registry uses
the source only for concise factual metadata and attribution; it does not copy
the site's marketing language or imagery.
